# 给 agent 的一句话指令模板

把下面这段里的信息替换成你的实验，连同原始数据照片一起发给 agent 即可。
`lab-report-b5` 的 `SKILL.md` 会让它按固定流程执行并自检。

---

## 基础版（推荐）

> 用 `lab-report-b5` 模板处理这个实验：原始数据在 `原始数据1.jpg`（第二页在 `原始数据2.jpg`）。
>
> - 第一部分：横版表格（宽高比 3~5），数据与频率的关系图（16:9），线性拟合给出表达式和 R²，并计算目标物理量及相对误差；
> - 第二部分：左右两个区各 3 列的数据表，两种条件下的曲线图（带图例），并估计特征值；
> - 第三部分：两张小表 + 一张 16:9 拟合图（宽高比 ≥ 2.5）。
>
> 全部按 B5、左右 20 mm 页边距排版，输出 PDF；每页内容不得溢出。

## 更省事的版本（让 agent 自己决定版式）

> 用 `lab-report-b5` 把这些原始数据排成可打印的 B5 数据处理页：
> 表格用三线表，图按版心宽度出，能拟合的都拟合并标注表达式和 R²。
> 数据在 `原始数据*.jpg`，物理量关系按实验原理来。

---

## 需要额外说明的常见情况

- **数据是扫描件/手写**：加一句“先逐项核对数字，把识别结果列出来给我确认，再排版”。
- **要复现某次成品**：加一句“参照 `examples/1105-photoelectric/` 的版式”。
- **有指定的表格结构**：把列名、分区方式、行数写清楚，agent 会照做；
  行数放不下时会自动改成两区/多区（本次 1105 的 22 行表就是这样来的）。
- **不想装 Python**：说“只要 Word/LaTeX 版”，agent 会按
  `references/page-geometry.md` 的尺寸给排版参数。
